# 关于本站

**开源文艺**是一个由社区共同维护的文学与艺术创作分享平台。所有内容以 Markdown 格式存储在 Git 仓库中，通过静态站点生成器构建为纯 HTML 页面，托管在 GitHub Pages 上。

## 这个网站如何运作

每位作者拥有自己独立的 Git 仓库（托管在 GitHub、Gitee 或自建 Git 服务上），自行存放、管理自己的文稿。本仓库**不直接收录**任何作者的原始文件——它只记录一条指向作者仓库的链接，这条链接在 Git 中叫做 **submodule**（子模块），指向作者仓库的一个特定 commit。

这意味着：

- **内容永远归作者所有**：作者的文稿始终存放在自己的仓库里，随时可以编辑、删除、设为私有、甚至迁移到其他平台。本仓库只保留了一条历史的引用，没有副本，也没有"上交"。
- **投稿只需一个链接**：作者通过配套的 `soil` 工具（或直接在 `.gitmodules` 中新增一条 submodule 记录）投稿。非程序员也能独立完成，无需学习 Git。
- **站点构建时拉取内容**：每次站点重新构建时，构建工具 `sitegen` 会根据 submodule 记录从每位作者的仓库中 checkout 各自的文稿，全部转为纯 HTML 静态页面。
- **安全感来自独立性**：即使这个站点仓库明天消失，你的文稿在自己的仓库里完好无损；反过来，如果你决定不再参与，只需移除那条 submodule 记录——站点上就没有你的内容，但你自己的仓库不受任何影响。

网站完全由静态 HTML 文件组成，不依赖任何后端、数据库或动态脚本。任何人都可以随时克隆整个站点，在任何地方离线浏览。

## 为什么采用 GitHub Pages

- **不被个人意志左右**——站点内容分布在多位作者的独立仓库中，任何人都可以 Fork 整个站点。不存在单一个人或组织可以下架或删除全部内容。
- **永久存在**——只要 GitHub 还存在，这个站点就永远在线。即使本仓库被删除，任何 Fork 副本都可以重新部署。
- **完全透明**——所有内容的历史版本与修改记录都在 Git 日志中公开可见，谁在什么时候写了什么，一目了然。
- **零成本**——GitHub Pages 免费提供全球 CDN 托管。

## 打破商业平台的数据壁垒

当下大量优质的个人创作被封闭在商业平台的高墙之内：算法决定谁能看到什么；内容可能因政策变化或商业利益被随时下架；API 受限导致搜索引擎与 AI Agent 难以获取完整文本；读者被迫注册、登录并接受追踪。

开源文艺选择了一条相反的路：所有内容以原始格式公开，无付费墙，无追踪，无算法干预。任何人——包括自动化工具与 AI——都可以自由访问、阅读、存档和再分发这些文字。文本而非流量，是我们唯一关心的东西。
